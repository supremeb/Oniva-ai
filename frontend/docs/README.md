## Documentation Standards

This documentation follows these principles:

### Progressive Disclosure

- **Getting Started**: Broad overview, minimal technical depth
- **User Guides**: Role-specific, practical focus
- **Features**: Moderate technical detail with examples
- **Concepts**: Deep technical architecture
- **API Reference**: Complete technical specification

### Real-World Examples

All tutorials use realistic financial services scenarios:
- Loan application processing
- KYC/AML verification
- Portfolio analysis
- Suspicious activity detection
- Regulatory compliance workflows

### Regulatory Context

Where relevant, documentation references:
- **FCA** (Financial Conduct Authority)
- **SOX** (Sarbanes-Oxley Act)
- **GDPR** (General Data Protection Regulation)
- **EU AI Act** (Artificial Intelligence Act)
- **BSA/AML** (Bank Secrecy Act / Anti-Money Laundering)

### Code Examples

API documentation includes examples in:
- **Python** (primary)
- **TypeScript** (frontend/Node.js)
- **cURL** (HTTP requests)
