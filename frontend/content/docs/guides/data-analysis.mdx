Learn how to create a workflow that automatically analyzes data from multiple sources and generates insights.

## What You'll Build

A workflow that:
1. Retrieves data from an API
2. Processes and transforms the data
3. Runs analysis using the Analysis Agent
4. Generates a summary report
5. Sends results via notification

## Prerequisites

<Callout type="info">
Before starting, ensure you have:
- Oniva account with API key configured
- Basic understanding of workflows (see [Core Concepts](/docs/getting-started/core-concepts))
</Callout>

## Step 1: Create a New Workflow

<Steps>
  <Step>
    Navigate to **Workflows** in the sidebar
  </Step>
  <Step>
    Click **+ New Workflow**
  </Step>
  <Step>
    Name it "Data Analysis Pipeline"
  </Step>
  <Step>
    Click **Create**
  </Step>
</Steps>

## Step 2: Configure the Start Node

The Start node defines your workflow inputs.

<Steps>
  <Step>
    Click on the **Start** node
  </Step>
  <Step>
    Add input variables:
    - `data_source_url` (string): The API endpoint to fetch data from
    - `analysis_type` (string): Type of analysis (summary, trends, anomalies)
  </Step>
</Steps>

## Step 3: Add HTTP Node for Data Retrieval

<Steps>
  <Step>
    Drag an **HTTP Request** node from the sidebar
  </Step>
  <Step>
    Connect it to the Start node
  </Step>
  <Step>
    Configure:
    - **Method**: GET
    - **URL**: `{{input.data_source_url}}`
    - **Headers**: Add any required authentication
  </Step>
</Steps>

## Step 4: Add Code Node for Data Transformation

<Steps>
  <Step>
    Drag a **Code** node onto the canvas
  </Step>
  <Step>
    Connect it to the HTTP node
  </Step>
  <Step>
    Add transformation code:

    ```python
    # Access data from previous node
    raw_data = nodes.http_request.response

    # Transform the data
    import json
    data = json.loads(raw_data) if isinstance(raw_data, str) else raw_data

    # Clean and prepare for analysis
    processed = {
        "records": len(data.get("items", [])),
        "data": data.get("items", [])
    }

    return processed
    ```
  </Step>
</Steps>

## Step 5: Add Analysis Agent Node

<Steps>
  <Step>
    Drag an **Agent** node onto the canvas
  </Step>
  <Step>
    Connect it to the Code node
  </Step>
  <Step>
    Configure:
    - **Agent**: Analysis Agent
    - **Instructions**:
    ```
    Analyze the following data and provide insights based on {{input.analysis_type}} analysis.

    Data: {{nodes.code.output}}

    Provide:
    1. Key findings
    2. Notable patterns or anomalies
    3. Recommendations
    ```
  </Step>
</Steps>

## Step 6: Add Template Node for Report

<Steps>
  <Step>
    Drag a **Template** node
  </Step>
  <Step>
    Connect it to the Agent node
  </Step>
  <Step>
    Configure the template:

    ```markdown
    # Data Analysis Report

    **Generated**: {{timestamp}}
    **Analysis Type**: {{input.analysis_type}}
    **Records Analyzed**: {{nodes.code.output.records}}

    ## Summary
    {{nodes.agent.response}}

    ---
    *Report generated by Oniva*
    ```
  </Step>
</Steps>

## Step 7: Add End Node

<Steps>
  <Step>
    Drag an **End** node
  </Step>
  <Step>
    Connect it to the Template node
  </Step>
  <Step>
    Configure output: `{{nodes.template.output}}`
  </Step>
</Steps>

## Step 8: Save and Test

<Steps>
  <Step>
    Click **Save**
  </Step>
  <Step>
    Click **Execute**
  </Step>
  <Step>
    Enter test inputs:
    - `data_source_url`: Your API endpoint
    - `analysis_type`: "summary"
  </Step>
  <Step>
    Watch the execution in real-time
  </Step>
</Steps>

## Complete Workflow Diagram

```
Start (inputs)
    ↓
HTTP Request (fetch data)
    ↓
Code (transform)
    ↓
Agent (analyze)
    ↓
Template (format)
    ↓
End (output)
```

## Tips

<Callout type="info">
- **Error Handling**: Add IF/ELSE nodes to handle API failures
- **Caching**: Store results to avoid re-fetching unchanged data
- **Scheduling**: Use Schedule Trigger for automated daily analysis
</Callout>
