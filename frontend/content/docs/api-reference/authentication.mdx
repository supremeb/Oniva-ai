Learn how to authenticate with the Oniva API using JWT tokens and API keys.

## Overview

Oniva uses two authentication methods:

| Method | Use Case | TTL |
|--------|----------|-----|
| **JWT Tokens** | Session-based authentication | 15 minutes |
| **API Keys** | Programmatic access | Until revoked |

---

## JWT Authentication

### Obtaining a Token

```bash
POST /api/v1/auth/token
Content-Type: application/json

{
  "username": "your-username",
  "password": "your-password"
}
```

**Response:**

```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIs...",
  "token_type": "bearer",
  "expires_in": 900
}
```

### Using the Token

Include the token in the Authorization header:

```bash
GET /api/v1/agents
Authorization: Bearer eyJhbGciOiJIUzI1NiIs...
```

### Refreshing Tokens

```bash
POST /api/v1/auth/refresh
Authorization: Bearer your-current-token
```

<Callout type="warn">
Tokens expire after 15 minutes. Implement automatic refresh to maintain sessions.
</Callout>

## API Key Authentication

### Generating an API Key

<Steps>
  <Step>Navigate to **Settings** → **API Keys**</Step>
  <Step>Click **Generate New Key**</Step>
  <Step>Copy the key (shown only once)</Step>
  <Step>Store securely in your application</Step>
</Steps>

### Using API Keys

Include the key in the X-API-Key header:

```bash
GET /api/v1/agents
X-API-Key: sk_live_abc123...
```

Or as a query parameter (not recommended for production):

```bash
GET /api/v1/agents?api_key=sk_live_abc123...
```

## LLM Provider Keys

Configure API keys for LLM providers in the dashboard.

<Tabs items={['OpenAI', 'Anthropic', 'Google']}>
  <Tab value="OpenAI">
    **Getting Your Key:**
    1. Go to [platform.openai.com/api-keys](https://platform.openai.com/api-keys)
    2. Create a new API key
    3. Copy and save in Oniva Settings

    **Required Permissions:**
    - Model access for GPT-4o or GPT-4o Mini
  </Tab>
  <Tab value="Anthropic">
    **Getting Your Key:**
    1. Go to [console.anthropic.com](https://console.anthropic.com)
    2. Navigate to API Keys
    3. Create a new key and save in Oniva

    **Required Permissions:**
    - Access to Claude 3.5 Sonnet
  </Tab>
  <Tab value="Google">
    **Getting Your Key:**
    1. Go to [aistudio.google.com](https://aistudio.google.com)
    2. Get API key for Gemini
    3. Save in Oniva Settings

    **Required Permissions:**
    - Gemini API access
  </Tab>
</Tabs>

## Security Best Practices

<Accordions>
  <Accordion title="Key Storage">
    - Never commit API keys to version control
    - Use environment variables in production
    - Rotate keys regularly (every 90 days recommended)
    - Use separate keys for development and production
  </Accordion>
  <Accordion title="Access Control">
    - Use the principle of least privilege
    - Create scoped keys when possible
    - Monitor key usage in audit logs
    - Revoke unused keys immediately
  </Accordion>
  <Accordion title="Transport Security">
    - Always use HTTPS in production
    - Verify SSL certificates
    - Don't expose keys in URLs or logs
  </Accordion>
</Accordions>

## Error Responses

| Status | Error | Description |
|--------|-------|-------------|
| 401 | `invalid_token` | Token is expired or malformed |
| 401 | `invalid_api_key` | API key is invalid |
| 403 | `insufficient_permissions` | Key lacks required scope |
| 429 | `rate_limit_exceeded` | Too many requests |

**Example Error Response:**

```json
{
  "error": "invalid_token",
  "message": "The provided token has expired",
  "code": 401
}
```
