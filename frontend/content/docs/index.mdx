## What is Oniva?

Oniva is an enterprise platform that enables you to:

- **Build AI Agents**: Create custom AI agents with specialized capabilities for your domain
- **Visual Workflow Builder**: Design complex multi-step workflows using a drag-and-drop interface
- **Execute Autonomously**: Run workflows that combine multiple agents, tools, and data sources
- **Ensure Compliance**: Built-in audit trails, approval workflows, and compliance checks

## Platform Features

### AI Agents

Oniva includes 8 built-in AI agents optimized for enterprise tasks:

| Agent | Purpose |
|-------|---------|
| **General Assistant** | Conversational AI helper for general interactions |
| **Data Retrieval Agent** | Fetch data from APIs, databases, and connectors |
| **Analysis Agent** | Perform data analysis and generate insights |
| **Compliance Agent** | Run regulatory compliance checks |
| **KYC/AML Agent** | Customer verification and anti-money laundering |
| **Market Abuse Agent** | Detect insider trading and manipulation |
| **Regulatory Report Generator** | Create formal compliance reports |
| **Research Agent** | Search documents using RAG |

[Learn more about AI Agents →](/docs/features/ai-agents)

### Visual Workflow Builder

Design complex workflows using React Flow-based visual editor:

- Drag-and-drop node creation
- Connect agents, conditions, and actions
- Real-time execution visualization
- Version control and collaboration

[Explore Workflows →](/docs/features/workflows)

### 34+ Built-in Skills

Agents have access to a rich library of skills:

- **Web Skills**: Search, browse, extract data
- **Code Skills**: Execute Python, analyze code, generate charts
- **File Skills**: Read, write, parse documents
- **Integration Skills**: Connect to external services

[View Skills Library →](/docs/features/skills-library)

### 36 Pre-built Connectors

Connect to popular services out of the box:

- Stripe, PayPal, Square (Payments)
- Slack, Teams, Discord (Communication)
- GitHub, GitLab, Jira (Development)
- HubSpot, Salesforce, Zendesk (CRM)

[Configure Connectors →](/docs/features/connectors)
